## Ciberseguridad & IA

- **Incidente masivo en AUR: 400+ paquetes de Arch hijacked con malware Rust.** Atacantes comprometieron más de 400 paquetes en Arch User Repository reescribiendo scripts de compilación para instalar un robo-credenciales en Rust. El malware puede cargar un rootkit eBPF si se ejecuta como root. Avisos: revisar todos los cambios en PKGBUILD e install scripts al actualizar. Fuente: [Arch Linux News](https://archlinux.org/news/active-aur-malicious-packages-incident/), [The Hacker News](https://thehackernews.com/2026/06/400-arch-linux-aur-packages-hijacked-to.html). Conecta con: [[arch-linux]], [[ciberseguridad]]

- **China-Linked Hackers Backdoored Linux Login Software during Nearly a Decade.** Grupo vinculado a China (Velvet Ant/Sygnia) comprometió PAM y OpenSSH para permanecer oculto en sistemas sin detección. La persistencia en el sistema de login es más efectiva que malware tradicional. Fuente: [The Hacker News](https://thehackernews.com/2026/06/china-linked-hackers-backdoored-linux.html). Conecta con: [[linux]], [[ciberseguridad]]

Se dispara mediante reportes de error falsos en Sentry (error-tracking open source). Implicación: riesgo para dev machines ejecutando herramientas IA. Afecta aplicaciones de agentes IA auto-hospedadas. Fuente: [The Hacker News](https://thehackernews.com/2026/06/langgraph-flaw-chain-exposes-self.html). Conecta con: [[ia]], [[ciberseguridad]]
